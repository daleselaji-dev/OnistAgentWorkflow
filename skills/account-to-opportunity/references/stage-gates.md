# Stage Gates

Use repository contracts as normative detail.

- Discovery: no fake completeness, no unauthorized source access, candidate != qualified.
- Evidence: no wrong entity merge, unsupported decision-bearing claim, or not-found-as-negative.
- Qualification: hard gates non-compensable; no uncalibrated probability claims.
- Buying committee: company intent != personal intent; title alone != ownership/authority proof.
- Persuasion: no borrowed ROI, unsupported pain, or epistemic-label upgrade.
- Execution: unknown jurisdiction blocks live action; substantive reply pauses the account-product motion; no blind retry; suppression cannot be bypassed.
- Measurement/Learning: attribution != causality; C0/C1 cannot promote performance optimization; data-quality failure blocks causal learning; rollback is required for global policy changes.
