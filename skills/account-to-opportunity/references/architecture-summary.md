# Architecture Summary

Canonical runtime spine:

`Router -> Market Universe -> Evidence -> Qualification -> Buying Committee -> Value Hypothesis -> Governed Execution -> Measurement -> Controlled Learning -> Versioned Policy -> loop`

Use a durable deterministic orchestrator for state, identity, approval, suppression, idempotency, event joins and policy promotion. Use bounded agents for open-world discovery, research synthesis, role hypotheses and value-hypothesis construction. `UNKNOWN/HOLD` is a first-class state. Hard gates are non-compensable.

See `../../../docs/architecture.md` for the full architecture and `../../../contracts/` for machine-readable policies.
